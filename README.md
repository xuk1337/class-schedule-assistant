# 班级课表助手

班级课表助手采用 Flask、SQLite 和原生 HTML/CSS/JavaScript 实现，支持学生、
班级管理员和系统管理员三种角色。正式系统源码与项目文档分开存放。

## 正式系统

进入 `班级课表助手_正式系统/` 后执行：

```powershell
py -3 -m pip install -r requirements.txt
py -3 app.py
```

启动后访问：

- 课表与登录页面：`http://127.0.0.1:5000/`
- 系统管理后台：`http://127.0.0.1:5000/admin`

运行自动化测试：

```powershell
py -3 -m pip install -r requirements-dev.txt
py -3 -m pytest -q
```
