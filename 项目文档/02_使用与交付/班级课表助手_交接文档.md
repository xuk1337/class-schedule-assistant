## 2. 项目做了什么（宣讲时讲这些）

一个**全班共用**的课表与作业管理系统，解决"课表分散在教务系统/截图/聊天记录里、作业截止时间靠互相问"的问题。三种角色：

- **学生**：凭"姓名 + 学号 + 班级邀请码"激活账号 → 看本班统一课表（周视图/日视图）、**考试倒计时**、**作业提醒（逾期标红、临期标橙）**、搜索课程、导出 PDF 课表。学生全程**只读**。
- **班级管理员**（学委/课代表）：维护课程（**一门课可排多个时段**，如高数周一+周三）、增删改作业、**双 CSV 一键导入全班课程+作业**（任一错误整体回滚不污染数据）、邀请码泄露时可**一键重置**。
- **系统管理员**：独立后台——建学期、建班级、导入学生名单、任命/交接班级管理员、停用/转班/重置密码、查看**审计日志**。

技术要点（评委追问时用）：Flask 3.1 + SQLite（9 张表）、服务端 Session + CSRF 防护 + 密码哈希、**服务端时间冲突检测**（返回 409）、数据库条件唯一索引保证"每班只有一个管理员、全校只有一个进行中学期"、导入导出全走事务、**70 项自动化测试全部通过**。

## 3. 怎么启动

### 情况 A：在当前 Windows 电脑上演示（推荐）

1. 打开 PowerShell，执行：
   ```powershell
   cd D:\桌面\班级课表助手\班级课表助手_正式系统
   py -3 app.py
   ```
2. 浏览器打开 **http://127.0.0.1:5000/** （课表端）和 **http://127.0.0.1:5000/admin** （系统管理后台）。
3. 如果页面样式异常，按 **Ctrl+Shift+R** 强制刷新。

### 情况 B：换一台电脑从零搭建

1. 要求：安装 **Python 3.9 或更高版本**。
2. Windows PowerShell：
   ```powershell
   cd 班级课表助手_正式系统
   py -3 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe scripts\seed_dev.py
   .\.venv\Scripts\python.exe app.py
   ```
3. macOS 或 Linux：
   ```bash
   cd 班级课表助手_正式系统
   python3 -m venv .venv
   ./.venv/bin/python -m pip install -r requirements.txt
   ./.venv/bin/python scripts/seed_dev.py
   ./.venv/bin/python app.py
   ```
4. 浏览器打开 http://127.0.0.1:5000/ 。
   > 压缩包里已带一份灌好数据的数据库（`instance/classschedule.db`），跳过 seed 直接 `python app.py` 也能跑；但一旦跑过 seed，**邀请码会重新生成**，以终端那次输出为准。

### 端口被占了怎么办

`python app.py` 默认 5000 端口。提示 Address already in use 就换个方式启动：
```powershell
.\.venv\Scripts\python.exe -c "from app import create_app; create_app().run(port=5001)"
```
然后访问 http://127.0.0.1:5001/ 。

## 5. 建议演示动线（约 8-10 分钟，对应评分点）

**① 开场（30 秒）**："课表分散、作业靠问，我们做了一个班级共享课表系统。"打开登录页。

**② 学生激活（1 分钟）**：点「激活学生账号」→ 填姓名（后台名单里的）、学号 `2023301006`、邀请码、自设密码 → 激活成功直接进课表。
*讲解点：学生不是自由注册，必须匹配系统管理员预置的名单 + 邀请码，防止外人混入。*

**③ 学生视角（2 分钟）**：周视图指给别人看——彩色课程块、**今天那列高亮**、顶部**考试倒计时**和**作业提醒（逾期红/临期橙）**；切**日视图**；用**搜索框**过滤"高等数学"；点「导出PDF」调起打印（横向课表）后取消即可。
*讲解点：一班一表、课表即提醒；学生全程只读，没有任何编辑按钮。*

**④ 班级管理员视角（3 分钟）**：退出，登录 `admin2301`。
- 点开「高等数学」→ 编辑 → 展示**一门课两个时段**（周一 1-2 节 + 周三 3-4 节）；
- 演示**冲突检测**：把某个时段改到和别的课重叠 → 保存被拒，提示"与《XX》时间冲突！"；
- 点课程详情里加一条作业（截止选明天）→ 回到主页作业提醒立即出现；
- 打开「更多 → 导入课程+作业」展示**双 CSV 导入**弹窗（不真导，或提前备好两份 CSV 真导一次）；
- 「班级设置 → 重新生成邀请码」→ 展示**明文只出现一次**的弹窗。
*讲解点：录入不出错（服务端冲突检测）；批量导入是事务，错一行全部回滚；邀请码只存摘要。*

**⑤ 系统管理员后台（2 分钟）**：使用账号 `sysadmin`、密码 `sysadmin123` 登录 `/admin`。
- 学期管理（唯一进行中学期）、班级管理（两个班）；
- **学生名单**：展示待激活/已启用状态，现场导入一小段名单（可选）；

- **审计日志**：刚才所有操作都有记录。
*讲解点：数据按班隔离，管理员只能管自己的班；所有关键操作留痕。*

**⑥ 收尾（30 秒）**："后端 9 张表全部服务端校验，70 项自动化测试通过；权限、事务、审计都按正式系统标准做的。"

## 6. 演示注意事项（重要！）

1. **别在演示中真做这些破坏性操作**：管理员交接（旧账号会立刻登录不了）、停用账号、真的覆盖导入。想展示就指着讲，或者说"这里就不真点了"。
2. **演示前一天**：打开终端跑一遍启动命令 + 三个角色都登录一遍，确认没问题。数据乱了就恢复：在正式系统目录运行 `.\.venv\Scripts\python.exe scripts\seed_dev.py`（**跑完邀请码会变**，记新码）。
3. **邀请码对不上** = 有人重灌了种子。看那次终端输出，或数据库没法直接查（只存摘要，这是设计如此，评委问了可以当亮点讲）。
4. **浏览器缓存**：换过代码或样式后，页面异常就按 Ctrl+Shift+R 强刷。
5. **PDF 导出**用的是浏览器自带打印：点导出后选"另存为 PDF"即可；打印窗口取消不影响系统。
6. **投影仪分辨率低**时页面可能挤：浏览器缩小（Ctrl+-）到 80-90% 即可，系统是响应式的。
7. 演示机如果息屏/重启过，记得重新执行启动命令（服务是前台进程，终端关了服务就停）。
8. 登录连续输错 5 次会锁 5 分钟（安全特性）——演示前确认密码没抄错；真被锁了就等 5 分钟或重启服务。

## 7. 评委可能的提问 & 应答口径

- **"学生数据哪来的？"** → 系统管理员从辅导员确认的名单批量导入，学生凭名单+邀请码激活，不能自由注册。
- **"怎么防止学生改数据/看别班？"** → 所有写接口服务端鉴权，学生写请求直接 403；班级范围从服务端 Session 推导，前端传 class_id 也没用，跨班访问返回 404。
- **"邀请码安全吗？"** → 安全随机生成，数据库只存 SHA-256 摘要，明文只在生成时展示一次，泄露可一键重置、旧码立即失效，审计日志不落明文。
- **"CSV 导入失败会怎样？"** → 两份文件统一校验，任何一行错（含行号报错）整体不保存；校验通过后也在一个事务里先删后写，中途失败整体回滚，不影响其他班级。
- **"为什么用 SQLite？"** → 课程级项目单班数据量小，SQLite 零部署、支持事务和外键；数据访问层集中在 db.py，迁 MySQL 只换驱动和方言。
- **"测试过吗？"** → 70 项 pytest 自动化测试：数据库约束、三角色权限、冲突检测、导入回滚、邀请码、审计，全部通过。
- **"有什么亮点？"** → 一课多时段、双 CSV 原子导入、动态邀请码、条件唯一索引（每班一管理员/唯一进行中学期）、冲突检测 409、审计日志、70 项测试。
