# 班级课表助手 · 使用手册

> 适用版本：正式系统 v1.0  
> 适用对象：学生、班级管理员、系统管理员、演示与维护人员

## 1. 系统简介

班级课表助手用于集中管理班级课表和共享作业。系统中的课程、作业和课表按班级、学期隔离，同班学生查看同一份数据。

系统包含三种角色：

| 角色 | 主要权限 |
|---|---|
| 学生 | 激活账号、查看本班课表和作业、搜索课程、切换周/日视图、导出 PDF |
| 班级管理员 | 拥有学生的查看权限，并可维护本班课程、上课安排、作业、双 CSV 导入和班级邀请码 |
| 系统管理员 | 管理学期、班级、学生名单、班级管理员、账号状态和审计日志 |

重要规则：

- 学生不能自由注册，必须先由系统管理员导入名单，再凭姓名、学号和班级邀请码激活。
- 学生对课程和班级共享作业只有读取权限。
- 班级管理员只能维护自己所属班级的数据。
- 系统管理员使用独立后台，不参与班级日常课表维护。

## 2. 运行环境

### 2.1 环境要求

- Python 3.9 或更高版本
- Edge、Chrome 等现代浏览器
- Windows、macOS 或 Linux

正式系统目录：

```text
班级课表助手_正式系统/
```

### 2.2 Windows 启动

在“班级课表助手”目录打开 PowerShell：

```powershell
cd .\班级课表助手_正式系统
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

### 2.3 macOS 或 Linux 启动

```bash
cd 班级课表助手_正式系统
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python app.py
```

启动后访问：

| 页面 | 地址 |
|---|---|
| 课表与登录页面 | `http://127.0.0.1:5000/` |
| 系统管理后台 | `http://127.0.0.1:5000/admin` |

关闭运行服务时，在启动服务的终端按 `Ctrl+C`。

### 2.4 演示数据

项目已包含演示数据库时，可以直接启动，不需要重新生成数据。演示账号见：

```text
项目文档/04_答辩材料/答辩素材/演示账号.md
```

需要恢复演示初始状态时，在正式系统目录执行：

```powershell
.\.venv\Scripts\python.exe scripts\seed_dev.py
```

该命令会清理并重新生成演示数据，同时生成新的班级邀请码。旧邀请码立即失效，执行前应确认不需要保留现有数据。

## 3. 登录与退出

### 3.1 学生登录

1. 打开课表页面。
2. 选择“学生登录”。
3. 输入学号和密码。
4. 点击“登录”。

登录后只能看到本人所属班级和当前学期的数据。

### 3.2 班级管理员登录

1. 打开课表页面。
2. 选择“班级管理员”。
3. 输入管理员账号和密码。
4. 点击“登录”。

管理员账号不开放自助注册，由系统管理员统一创建或交接。

### 3.3 系统管理员登录

1. 打开 `http://127.0.0.1:5000/admin`。
2. 输入系统管理员账号和密码。
3. 点击“登录”。

系统管理员登录课表页面时，系统也会引导进入管理后台。

### 3.4 退出

点击页面右上角的账号区域或“退出登录”。退出后会话失效，再次操作需要重新登录。

## 4. 学生账号激活

学生首次使用前，系统管理员必须已经完成：

1. 创建并启用学期。
2. 创建学生所属班级。
3. 将学生姓名和学号导入该班名单。
4. 将当前有效的班级邀请码线下发送给学生。

学生激活步骤：

1. 在登录页点击“激活学生账号”。
2. 填写真实姓名。
3. 填写学号。
4. 填写班级邀请码。
5. 设置不少于 8 位的密码。
6. 点击“激活”。

姓名、学号、班级和邀请码必须与待激活名单一致。激活成功后，按页面提示直接进入系统或使用新密码重新登录。

以下情况无法激活：

- 姓名或学号与导入名单不一致。
- 学号不在待激活名单中。
- 邀请码错误或已经失效。
- 账号已经激活、已被停用或所属班级已停用。

## 5. 学生功能

### 5.1 查看课表

登录后默认进入当前班级、当前学期的课表。

- 桌面端默认显示周视图。
- 移动端默认显示日视图。
- 使用“上一周”“下一周”切换周次。
- 周视图展示一周课程分布。
- 日视图展示所选日期的课程安排。

同一门课程可以包含多条上课安排，例如周一 1-2 节和周三 3-4 节。

### 5.2 查看课程详情

点击课程卡片可以查看：

- 课程编号和课程名称
- 教师
- 教室
- 星期、节次和有效周次
- 考试日期和备注
- 与该课程关联的班级作业

学生只能查看，不能添加、修改或删除课程和作业。

### 5.3 搜索课程

在顶部搜索框输入课程名、教师或教室。周视图和日视图会同步过滤匹配课程。

### 5.4 查看考试和作业提醒

页面顶部会展示近期考试和作业：

- 临近截止的作业会重点提示。
- 已逾期作业会使用警示状态显示。
- 作业内容由班级管理员统一维护，全班共享。

### 5.5 导出 PDF

1. 切换到需要导出的周次。
2. 点击“导出 PDF”。
3. 在浏览器打印窗口选择“另存为 PDF”。
4. 建议使用横向布局并保存。

导出内容为当前班级当前周的完整课表，不受页面搜索条件影响。

## 6. 班级管理员功能

班级管理员只能操作本人所属班级和当前学期的数据。

### 6.1 添加课程

1. 点击“添加课程”。
2. 填写课程编号、课程名、教师、考试日期和备注。
3. 添加一条或多条上课安排。
4. 每条安排填写教室、星期、开始节次、结束节次、起始周和结束周。
5. 点击“保存课程”。

服务端会检查本班当前学期的时间冲突。若星期相同、节次重叠且周次重叠，系统会拒绝保存并提示冲突课程。

### 6.2 编辑或删除课程

1. 点击课程卡片进入详情。
2. 点击“编辑课程与安排”修改课程或多条上课安排。
3. 点击“删除课程”可以删除课程。

删除课程会同时删除其全部上课安排和关联作业，操作不可恢复。

### 6.3 管理作业

1. 打开课程详情。
2. 输入作业内容和截止日期。
3. 点击添加。
4. 使用作业旁的编辑或删除操作维护已有作业。

作业修改后会立即同步给同班学生。

### 6.4 双 CSV 导入

在“更多”菜单中可以：

- 下载课程 CSV 模板。
- 下载作业 CSV 模板。
- 同时选择两份 CSV 并导入。

课程 CSV 固定表头：

```csv
课程编号,课程名,教师,教室,星期,开始节次,结束节次,起始周,结束周,考试日期,备注
```

作业 CSV 固定表头：

```csv
课程编号,作业内容,截止日期
```

导入规则：

- 文件使用 UTF-8 编码，支持 BOM。
- 两份文件必须同时选择，单个文件不超过 2MB。
- 同一课程编号可以出现多行，每行表示一条上课安排。
- 同一课程编号的课程名、教师、考试日期和备注必须一致。
- 作业中的课程编号必须存在于同批课程 CSV 中。
- 导入会整体覆盖本班当前学期的课程、安排和作业。
- 两份文件统一校验，任一行失败则全部不写入，原数据保持不变。

执行导入前应先备份重要数据，并认真确认覆盖提示。

### 6.5 管理班级邀请码

1. 打开“更多”菜单。
2. 进入“班级设置”。
3. 点击“重新生成邀请码”。
4. 确认后立即复制并妥善保存新邀请码。

新邀请码明文只展示一次。关闭窗口后无法再次查看，旧邀请码会立即失效，已经激活的学生账号不受影响。

## 7. 系统管理员功能

系统管理员后台包含学期管理、班级管理、学生名单、管理员管理和审计日志。

### 7.1 学期管理

- 创建学期时填写名称、第一周周一日期和总周数。
- 系统同一时间只允许一个进行中的学期。
- 启用新学期前应确认班级和课程数据准备情况。

### 7.2 班级管理

- 创建班级并设置班级代码、班级名称和所属学期。
- 创建班级时生成初始邀请码。
- 可以启用或停用班级。
- 班级停用后，学生不能继续激活，相关业务写入也会被拒绝。

### 7.3 导入学生名单

选择目标班级后，可以上传 CSV 或粘贴名单文本。

学生名单表头：

```csv
姓名,学号
```

导入后的学生状态为“待激活”，不设置默认密码。任一行存在错误时整批回滚。

### 7.4 任命或交接班级管理员

1. 进入“管理员管理”。
2. 选择班级。
3. 填写管理员姓名、登录账号和初始密码。
4. 确认任命或交接。

每个班级默认只有一个有效管理员。发生交接时，旧管理员立即失去该班管理权限，班级课程和作业数据不受影响。

### 7.5 管理账号

系统管理员可以：

- 启用或停用学生账号。
- 将学生调整到其他班级。
- 重置账号密码。
- 查看账号状态。

不得通过修改前端数据直接变更角色或班级。

### 7.6 查看审计日志

审计日志记录登录、激活、课程和作业维护、导入、邀请码重置、账号管理等关键操作。可以按操作类型、人员或时间筛选，用于问题追踪。

日志不得记录密码、密码哈希或邀请码明文。

## 8. 数据备份与恢复

默认数据库文件：

```text
班级课表助手_正式系统/instance/classschedule.db
```

演示或重要操作前，停止服务并复制该文件即可完成离线备份。恢复时：

1. 停止 Flask 服务。
2. 保存当前数据库副本。
3. 用备份文件替换 `classschedule.db`。
4. 重新启动服务。
5. 登录三种角色并检查班级、课程和作业数据。

生产环境应使用 SQLite 在线备份命令或受控备份脚本，并定期执行恢复演练。

## 9. 常见问题

### 9.1 启动提示端口被占用

使用其他端口启动：

```powershell
py -3 -c "from app import create_app; create_app().run(port=5001)"
```

然后访问 `http://127.0.0.1:5001/`。

### 9.2 页面样式或脚本没有更新

按 `Ctrl+F5` 强制刷新浏览器缓存。

### 9.3 连续登录失败

登录连续失败达到限制后会暂时锁定。确认账号和密码无误，等待锁定时间结束后再试。

### 9.4 学生无法激活

请依次检查：

1. 姓名和学号是否与系统管理员导入的名单完全一致。
2. 学生是否仍为待激活状态。
3. 班级是否启用。
4. 邀请码是否为最近生成的有效邀请码。

### 9.5 课程保存提示冲突

检查同一星期下的节次区间和周次区间。只要节次、周次同时重叠，就必须调整其中一个时间范围。

### 9.6 CSV 导入失败

检查文件编码、表头、日期格式、课程编号引用和课程字段一致性。系统返回的错误信息会标出对应行，修复全部错误后重新导入。

### 9.7 忘记邀请码

数据库不保存邀请码明文，无法找回。班级管理员只能重新生成，新码生成后旧码失效。

### 9.8 忘记密码

联系系统管理员重置密码。不要直接修改数据库中的密码字段。

## 10. 安全与使用注意事项

- 不要在群聊、截图、源码或日志中公开正式密码、密钥和邀请码。
- 演示账号和演示数据库不得直接用于生产环境。
- 生产环境必须设置独立 `SECRET_KEY` 并使用 HTTPS。
- 不要使用浏览器开发者工具伪造角色、班级或学期；服务端会执行最终鉴权。
- 不要在服务运行期间直接替换数据库文件。
- 双 CSV 导入、课程删除、管理员交接和邀请码重置均属于高影响操作，执行前应确认。

## 11. 维护与测试

在正式系统目录安装运行与测试依赖：

```powershell
py -3 -m pip install -r requirements-dev.txt
```

运行全部测试：

```powershell
py -3 -m pytest -q
```

当前正式系统共 70 项自动化测试；完整通过时结果应显示 `70 passed`。

测试通过后再进行浏览器端三角色回归，至少覆盖：

- 学生激活、登录和只读权限。
- 班级管理员课程、作业、冲突检测、双 CSV 和邀请码。
- 系统管理员学期、班级、名单、管理员交接和审计。
- 跨班访问、停用账号、CSRF 和敏感信息检查。
- 周/日视图、移动端和 PDF 导出。
