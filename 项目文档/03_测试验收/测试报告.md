## 五、CSV、PDF 与响应式

### 双 CSV

合法文件成功导入 1 门课程、1 条上课安排和 1 条作业。随后提交引用不存在课程
`UNKNOWN-01` 的作业文件，页面逐行报告错误，原 `UI-CSV-01` 数据仍然存在，
证明统一校验和事务回滚生效。

### PDF

- 点击“导出 PDF”后确认 `window.print()` 被调用。
- 存在横向 `@media print` 和 `@page` 打印样式。
- 打印样式恢复完整周视图，并取消搜索结果的透明过滤。

本轮未对不同操作系统生成的 PDF 二进制文件做像素级对比。

### 响应式

390 × 844 登录页和登录后主页面均通过检查。最终复测数据：

```json
{
  "clientWidth": 390,
  "scrollWidth": 390,
  "bodyWidth": 390,
  "overflow": false,
  "mobileMedia": true
}
```

课表自身保持横向滚动，不再撑宽整个页面。

## 六、安全与性能

安全检查结果：

- 未登录访问业务 API 返回 HTTP 401 和统一 JSON 错误体。
- CSRF、角色、账号状态、班级和学期范围均由服务端校验。
- 学生写入、跨班访问、停用账号和错误邀请码均有自动化测试。
- 响应包含 `X-Content-Type-Options: nosniff`、`X-Frame-Options: DENY`
  和 `Referrer-Policy: same-origin`。
- 密码使用 Werkzeug 哈希；邀请码数据库只存摘要，重置后旧码失效。
- 审计测试确认密码、邀请码和 CSRF 令牌不进入审计详情。

主页 20 次本地 HTTP 冒烟结果：

| 指标 | 结果 |
|---|---:|
| 平均响应时间 | 3.97 ms |
| P95 | 3.43 ms |
| 最大响应时间 | 27.18 ms |

该结果只用于发现明显性能退化，不替代并发和生产网络压测。

## 七、测试中发现并修复的问题
