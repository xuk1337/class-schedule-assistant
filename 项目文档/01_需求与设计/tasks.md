## 四、任务依赖关系

```
PRD与API基线(M0)
  → 工程骨架和9表迁移(M1)
    → 认证/系统管理/业务API(M2)
      → 前端改造与三角色联调(M3)
        → 安全/性能/回归验收(M4)
          → 备份恢复与发布演练(M5)
```

**关键依赖**：
- PRD 是唯一需求上游；字段或权限变化必须先更新 PRD、API 契约和迁移设计。
- `index.html` 只提供交互参考，不能直接复用其中的固定账号、邀请码、前端密码摘要或 `localStorage` 权限逻辑。
- B02 是 B04-B12 的前置；F01/F02 可基于契约先行开发，业务页面最终以真实 API 联调结果为准。
- 课程 CRUD 必须先完成 `courses/course_sessions` 分表和冲突服务，双 CSV 导入才能进入开发。
- 发布前必须完成跨班越权、事务回滚、备份恢复和生产配置检查。

### 完成定义（Definition of Done）

任务标记为“已验收”必须同时满足：代码已评审；数据库迁移可重复执行；接口契约和错误码已更新；自动化测试通过；三角色权限已覆盖；无密码、邀请码或密钥明文；相关文档已同步。仅在原型中可点击不算正式功能完成。

## 五、风险与应对

| 风险 | 影响 | 应对方案 | 负责人 |
|---|---|---|---|
| 原型代码被误当成正式安全实现 | 越权或敏感信息泄露 | 正式代码只信任 Session 和数据库；删除生产固定账号、固定邀请码和前端密码摘要 | 许宇坤 |
| 多时段课程仍按多门课程实现 | 作业重复、统计错误 | 先完成 `courses/course_sessions` 分表，前端和 CSV 均按课程编号聚合 | 许宇坤 |
| 批量导入误删其他班级或学期 | 严重数据污染 | 服务端从 Session 和 active 学期取范围，事务删除条件同时含 `class_id + semester_id` | 许宇坤 |
| CSV 中文、引号或字段内逗号解析错误 | 导入失败或错列 | 使用标准 CSV 解析器，支持 UTF-8 BOM，错误返回文件名与行号 | 许宇坤 |
| 邀请码泄露或被记录 | 未授权激活 | 安全随机生成、只存摘要、明文一次性展示、日志脱敏、支持立即重置 | 许宇坤 |
| 管理员交接出现两个有效账号 | 越权写入 | 条件唯一索引 + 同一事务停旧启新 + 并发测试 | 许宇坤、张耀伊 |
| SQLite 写锁影响导入 | 导入失败 | 缩短事务、设置合理 busy timeout、限制文件规模并返回可重试错误 | 许宇坤 |
| 学期起始日期配置错误 | 全部周次与日期偏移 | 强制第一周周一校验，启用前预览日期范围并二次确认 | 王思远、张耀伊 |
| PDF 打印遗漏搜索隐藏课程 | 导出不完整 | 打印时固定完整周视图，结束后恢复页面状态并做浏览器回归 | 张耀伊 |
| 备份不可恢复 | 正式数据丢失 | 发布前执行真实恢复演练并校验外键和关键记录数量 | 张耀伊 |
